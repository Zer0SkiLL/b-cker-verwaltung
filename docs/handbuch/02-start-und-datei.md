# Programm starten und Datei öffnen

Dieses Kapitel erklärt, wie Sie die Datei mit den Vereinsdaten öffnen oder neu anlegen.

## Datei öffnen

Beim Start zeigt das Programm die Startseite.

1. Steht unter **Zuletzt geöffnet** die richtige Datei, klicken Sie auf **Öffnen**.
2. Sonst klicken Sie auf **Datei öffnen…** und wählen die Datei aus, zum Beispiel auf dem Netzlaufwerk.

Danach sehen Sie die Seite **Adressen**. Beim nächsten Start bietet das Programm dieselbe Datei wieder an.

## Neue Datei anlegen

Nur nötig, wenn es noch gar keine Datei gibt, etwa beim allerersten Einsatz.

1. Klicken Sie auf **Neue Datei anlegen…**.
2. Wählen Sie Ort und Namen, zum Beispiel `Mitglieder.sqlite` auf dem Netzlaufwerk.

Eine neue Datei enthält bereits die vier Mitgliederkategorien und das Label „provisorisch“ in der Label-Gruppe „Aufnahme“.

## „Nur lesen“: wenn jemand anderes die Datei offen hat

Es darf immer nur eine Person gleichzeitig ändern. Hat jemand anderes die Datei schon geöffnet, erscheint oben eine gelbe Leiste, zum Beispiel:

> Nur lesen – geöffnet von anna (PC-SEKRETARIAT) seit 24.11.2026 08:12

Sie können dann alles ansehen, suchen und exportieren, aber nichts ändern. Knöpfe zum Ändern sind ausgegraut.

**Was tun?**

- Ist die andere Person noch am Arbeiten, warten Sie, bis sie das Programm schliesst. Öffnen Sie die Datei danach erneut.
- Steht in der Leiste „wahrscheinlich nach einem Absturz“, oder wissen Sie sicher, dass niemand mehr daran arbeitet (zum Beispiel weil die Hauptperson in den Ferien ist und das Programm offen gelassen hat), klicken Sie auf **Übernehmen**. Das Programm fragt nach und öffnet die Datei dann für Sie zum Ändern.

**Wichtig:** Wer die Datei vorher offen hatte, kann nach dem Übernehmen nichts mehr speichern. Sprechen Sie sich darum wenn möglich ab.

## Das Programm schliessen

Schliessen Sie das Fenster wie gewohnt. Das Programm gibt die Datei dabei frei. Ist ein zweiter Sicherungsort eingerichtet, legt es dort vorher eine Kopie ab (siehe [Datensicherung und Wiederherstellen](08-sicherung-wiederherstellen.md)).
